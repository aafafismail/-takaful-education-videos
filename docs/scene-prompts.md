# Scene image prompts — "Healing hari ini. Tenang juga esok."

19 images, all **vertical 9:16** (1080 × 1920 or larger).
Free tools that work well: **ChatGPT** (image generation), **Gemini**, **Meta AI**.

## How to get consistent results
1. Do all images **in the same chat**, in order.
2. For scenes with Aina, attach the **first good Aina image** as a reference and add: *"Same woman as the reference image."*
3. If a result has text, letters, logos or extra fingers, ask: *"Regenerate without any text or logos."*
4. Save each one with the exact file name shown (e.g. `s01.jpg`) and upload them here. JPG or PNG are both fine.

## Paste this STYLE line at the start of every prompt
> Cinematic semi-realistic 3D animated film still, warm painterly digital art like a modern Pixar/Disney feature, golden-hour lighting, soft volumetric haze and light rays, rich detail, Malaysian setting, vertical 9:16 composition with the main subject in the middle and some calm space at the top and bottom, no text, no letters, no logos, no watermark.
